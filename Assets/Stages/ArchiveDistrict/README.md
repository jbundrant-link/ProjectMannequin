# Archive District

Active MVP stage background:

```text
Assets/Stages/ArchiveDistrict/archive_district_stage_higgsfield_v1.png
```

The stage was generated through the Higgsfield CLI as an original modern arcade beat-em-up environment. Its composition reserves the lower portion for an unobstructed combat lane while using the upper portion for city, museum, transit, and archive-world storytelling.

`PrototypeStageView` presents the image as an unshaded 3D background plane behind all actors. Gameplay movement and combat remain independent from the artwork.
