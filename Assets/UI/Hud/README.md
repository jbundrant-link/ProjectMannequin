# Project Mannequin HUD

Active ornament overlay:

```text
Assets/UI/Hud/project_mannequin_lifebar_frame_higgsfield_v1.png
```

The overlay was generated through the Higgsfield CLI. It uses the mirrored information hierarchy of classic MUGEN lifebars as a layout reference while replacing all portraits, typography, pixels, colors, and ornament shapes with original Project Mannequin artwork.

The image contains only decoration. Health, meter, names, encounter status, and portraits remain live Godot controls in `MvpHud`.

Reference reviewed:

- PotS, `MUGEN1 Lifebar Remix`
- https://network.mugenguild.com/pots/

The PotS FAQ permits reuse and modification of PotS work, asks that derived content remain free, and requires checking individual readmes for third-party credits. The original package readme credits Elecbyte, the Ikemen GO team, and Lasombra Demon, so their raw sprites and audio were not copied into this project.
